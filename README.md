# Маленькая история для Саши

Открой `index.html` в браузере. Сайт не требует установки зависимостей.
Фоновая музыка берётся из `mayak.mp3` в той же папке и запускается после правильного ответа на загадку. Если браузер не разрешит автоматический запуск, нажми кнопку «Включить музыку».

## Настройка

В начале `script.js` находятся настройки:

- `answers` — допустимые ответы на загадку перед сайтом.
- `password` — пароль на первой странице с пингвином и замком.

После правильного ответа на загадку открывается первая страница с пингвином и замком. После правильного пароля запускается отдельная мини-игра: собери пять сердечек. Кнопка после игры ведёт на следующую страницу со смешным смайликом и четырьмя причинами. Третью причину нужно открыть тремя нажатиями на замок, а четвёртая показывает на весь экран анимированное голубое сердце с чередующимися надписями `I Love You` и `My Princess`.

Первые две причины — текстовые заготовки. Текст третьей меняется в `setupReasons()` в `script.js`. Для текста в центре сердца используй поиск по `самой любимой` в `index.html`. Картинка с пингвином лежит рядом с `index.html` в файле `penguin-love.png` — оставь оба файла в одной папке.
Для музыки оставь `mayak.mp3` в той же папке, что и `index.html`.

Ответ и пароль проверяются в браузере и служат загадкой и романтическим сюрпризом, а не настоящей защитой: правильные значения можно увидеть в исходном коде страницы.
